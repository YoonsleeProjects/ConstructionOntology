# Ontology supplement

**Integrating Construction Delivery and Asset Management Information: An Ontology-Based Model**

Hyuk Moon · Yoon-Sun Lee · Hoon-Ku Lee · Tai Sik Lee

Read the [HTML supplement](https://yoonsleeprojects.github.io/ConstructionOntology/) for the model, both figures, 19 classes, 12 relationships, six relation annotations, source descriptions, and nine connection review criteria. In a downloaded package, open `index.html` locally. Each term provides its definition, IRI, and relevant relationships. The [Turtle specification](infrastructure-continuity-spec.ttl) provides the corresponding machine-readable ontology.

This supplement contains the ontology documentation and figures. Original source records and the empirical case dataset are not included.
